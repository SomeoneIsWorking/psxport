# psxport agent instructions

This is the repository-local discovery entry point for agents that load `AGENTS.md`.

Read [`CLAUDE.md`](CLAUDE.md) completely before working in psxport or consuming it from a game
repository. That file is the canonical framework, port-architecture, build, runtime, rendering,
diagnostics, and registry authority; this shim deliberately does not duplicate its rules.

Before concurrent framework work, also read
[`docs/workspace/PROTOCOL.md`](docs/workspace/PROTOCOL.md) completely.
